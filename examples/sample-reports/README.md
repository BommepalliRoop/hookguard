# Sample CLI reports

These reports were generated by the compiled HookGuard CLI from the
[synthetic duplicate-payment scenario](../scenarios/duplicate.yaml).

| Express mode | Credit count | CLI exit code | JSON | JUnit |
| --- | --- | --- | --- | --- |
| Buggy | 3 | 1 | [buggy.json](buggy.json) | [buggy.xml](buggy.xml) |
| Fixed | 1 | 0 | [fixed.json](fixed.json) | [fixed.xml](fixed.xml) |

To verify both modes and regenerate the reports from the repository root, use
Node, pnpm, and Python 3.

```sh
pnpm install --frozen-lockfile
pnpm build
python3 scripts/phase5/verify_demo.py --reports examples/sample-reports
```

On Windows, use `py -3` if that is how Python is installed. The verifier checks
the exit status, asks each consumer for its actual credit count, and parses the
JSON and JUnit reports.

The JSON files retain the original observation timestamps and attempt durations.
Their scenario hashes include the configuration's ephemeral local port. The
timestamps, durations, and hashes can differ between runs.
