# Issue triage

Start with the [bug report form](../.github/ISSUE_TEMPLATE/bug_report.yml). Record the executable version, Node.js version, platform, exact command, and the smallest synthetic fixture that reproduces the failure. Include the expected assertion and actual exit code.

Reproduce on the stated version and latest checkout. Record whether the problem is in scenario parsing, transport, receiver behavior, or reporting. Link a regression test when available. Route vulnerabilities through the [security policy](../SECURITY.md) with sensitive evidence omitted from public discussion.
