# HookGuard — Codex instructions (public)

Build a useful local-first TypeScript webhook reliability test runner. Use the public plan files under `docs/plan/` for scope and milestones.

## Model routing
- GPT-6.2 Sol: normal implementation, tests, CLI, CI and documentation.
- GPT-6.2 Astra: architecture, security threat modeling, complex race conditions, final engineering reviews.
- GPT-6.1 Terra: visual testing only if a web dashboard is actually approved.
- GPT-6 Luna: optional narrow documentation edits.
Model selection is manual and availability varies; do not imply models are selected automatically.

## Rules
- Never fabricate completed tasks, tests, PRs or users.
- Implement one milestone at a time and run actual tests before claiming success.
- No paid APIs, production secrets, real customer webhook data, or unrestricted outbound network replay.
- Check `git status` and preserve existing work.
- Ask before public publishing, package releases, contacting external maintainers or opening external PRs.
- The OSS sponsorship plan and applicant financial details are **not** part of this public product repository.

## Deliverables per task
Summarize changed files, test results, remaining risks and next step.
