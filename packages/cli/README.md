# HookGuard CLI

HookGuard exercises local webhook consumers with repeatable delivery, retry, and security scenarios. It evaluates responses and application state and emits text, JSON, or JUnit reports.

Install an approved local tarball and check the CLI entry point.

```sh
npm install --global --ignore-scripts ./hookguard-cli-0.1.0-alpha.1.tgz
hookguard --help
```

The [HookGuard repository](https://github.com/BommepalliRoop/hookguard) contains the quickstart, sample scenario and synthetic fixtures. The package includes its MIT license and third-party notices.
